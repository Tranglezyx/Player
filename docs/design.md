# 修仙挂机小游戏 — 设计总览

| 项目 | 说明 |
|------|------|
| 类型 | 微信小游戏 / 2D 像素风 / 修仙挂机（Idle RPG） |
| 玩法 | 打怪获得灵石 → 消耗灵石自动修炼 → 突破境界变强 → 打更强的怪 |
| 美术 | 像素风（Pixel Art），固定场景战斗 |
| 策略 | 先轻后重 |

## 核心循环（两条并行线）

```
境界线：打怪 → 灵石 → 自动修炼（耗灵石换修为） → 突破境界
战力线：打怪 → 灵石 → 升级术法 → 熟练度提升 → 战力变强
```

### 模块依赖关系

```
人物模块 ←── 装备模块   (装备属性计入人物)
人物模块 ←── 境界模块   (境界决定基础属性)
人物模块 ←── 法术模块   (心法/术法挂载到人物)

战斗模块 ←── 人物模块   (读取攻击力等属性)
战斗模块 ←── 法术模块   (术法参与伤害计算)
战斗模块 →── 修炼模块   (灵石掉落支撑修炼消耗)

修炼模块 ←── 法术模块   (心法加速修炼)
修炼模块 →── 境界模块   (修为满触发升级/突破)

商店模块 ←── 人物模块   (灵石余额、等级决定商品数)
商店模块 →── 法术模块   (出售功法/残卷)
商店模块 →── 装备模块   (出售装备)
```
