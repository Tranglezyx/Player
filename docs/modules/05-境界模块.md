# 境界模块

> 修炼境界体系、突破条件与效果

## 境界序列

```
1. 炼气期    — 修仙入门，感知天地灵气
2. 筑基期    — 打下根基，寿命延长
3. 金丹期    — 凝结金丹，脱胎换骨
4. 元婴期    — 化丹成婴，神识初开
5. 化神期    — 元婴壮大，化身万千
6. 炼虚期    — 炼神返虚，洞悉法则
7. 合体期    — 天人合一，掌控一方
8. 大乘期    — 凡躯圆满，半步真仙
9. 渡劫期    — 天劫淬炼，九死一生
10. 真仙境   — 飞升仙界，长生不死
```

## 突破条件

```
1. 修为值达到当前上限（由修炼模块积累）
2. 灵石 ≥ 突破消耗
3. （后期可选）渡劫丹药 / 成功率判定
```

## 突破效果

| 效果 | 说明 |
|------|------|
| 攻击暴涨 | 攻击力按境界系数翻倍 |
| 灵力暴涨 | 灵力上限和回复速度大幅提升 |
| 解锁术法 | 每个境界解锁 1-2 个新术法 |
| 外观变化 | 不同境界对应不同像素精灵（白衣→青衣→紫衣→金衣...） |
| 新怪物区 | 解锁更高等级的怪物区域 |

## 境界属性系数

```
攻击力基数    = 10 * 1.6^(境界序号)
灵力上限基数  = 50 * 1.5^(境界序号)
灵力回复基数  = 1 * 1.3^(境界序号)
```

| 境界 | 攻击力 | 灵力上限 | 灵力回复/s |
|------|-------|---------|-----------|
| 炼气 | ~10 | 50 | 1.0 |
| 筑基 | ~25 | 113 | 1.7 |
| 金丹 | ~65 | 253 | 2.9 |
| 元婴 | ~166 | 569 | 4.8 |
| 化神 | ~425 | 1,281 | 8.2 |

## 突破流程

```
修为满 → 点击突破按钮
  → 检查灵石是否足够
    → 足够：扣除灵石 → 播放突破动画（金光/天雷特效）
      → 境界属性更新 → 灵力全满 → 新术法解锁通知 → 怪物区切换
    → 不足：提示"灵石不足，继续修炼获取"
```
