# 境界模块

> 修炼境界体系，每境界 10 级，突破后进入下一个境界

## 境界序列

```
境界 = 大境界（10个） × 小等级（每境10级）

1. 炼气期    — Lv 1~10   修仙入门，感知天地灵气
2. 筑基期    — Lv 11~20  打下根基，寿命延长
3. 金丹期    — Lv 21~30  凝结金丹，脱胎换骨
4. 元婴期    — Lv 31~40  化丹成婴，神识初开
5. 化神期    — Lv 41~50  元婴壮大，化身万千
6. 炼虚期    — Lv 51~60  炼神返虚，洞悉法则
7. 合体期    — Lv 61~70  天人合一，掌控一方
8. 大乘期    — Lv 71~80  凡躯圆满，半步真仙
9. 渡劫期    — Lv 81~90  天劫淬炼，九死一生
10. 真仙境   — Lv 91~100 飞升仙界，长生不死
```

**全局等级 = 境界序号 × 10 + 小等级**（如筑基三层 = 11 + 3 = 14 级）

## 修炼与升级

```
修炼累积修为 → 修为满 → 小等级 +1（自动）
  → Lv 10 且修为满 → 满足突破条件 → 点击突破 → 进入下一境界 Lv 1
```

- 小等级升级：修为满了自动升，不消耗灵石
- 境界突破：需修为满 + 灵石足够，手动操作

## 突破条件

```
1. 当前境界小等级达到 10
2. 修为值满
3. 灵石 ≥ 突破消耗
```

## 突破效果

| 效果 | 说明 |
|------|------|
| 攻击暴涨 | 攻击力按境界系数大幅提升 |
| 灵力暴涨 | 灵力上限和回复速度翻倍 |
| 解锁术法 | 每个境界解锁 1-2 个新术法 |
| 外观变化 | 不同境界对应不同像素精灵 |
| 新怪物区 | 解锁更高等级的怪物区域 |
| 小等级归 1 | 进入新境界后从小等级 1 重新开始 |

## 境界属性系数

```
攻击力基数    = 10 * 1.6^(境界序号)
灵力上限基数  = 50 * 1.5^(境界序号)
灵力回复基数  = 1 * 1.3^(境界序号)
```

小等级加成：在基数上线性增长

```
实际攻击 = 攻击力基数 * [1 + 0.1 * (小等级 - 1)]
实际灵力 = 灵力上限基数 * [1 + 0.1 * (小等级 - 1)]
```

| 境界 | 小等级范围 | 攻击力(1级/10级) | 灵力上限 | 灵力回复/s |
|------|----------|----------------|---------|-----------|
| 炼气 | 1~10 | 10 / 19 | 50~95 | 1.0 |
| 筑基 | 1~10 | 25 / 48 | 113~214 | 1.7 |
| 金丹 | 1~10 | 65 / 124 | 253~481 | 2.9 |
| 元婴 | 1~10 | 166 / 315 | 569~1081 | 4.8 |
| 化神 | 1~10 | 425 / 808 | 1281~2434 | 8.2 |

## 突破流程

```
小等级 10 + 修为满 → "突破"按钮亮起
  → 点击突破
    → 灵石足够：扣除灵石 → 播放突破动画
      → 境界+1 → 小等级→1 → 属性更新 → 灵力全满 → 新术法 → 新怪物区
    → 灵石不足：提示"灵石不足"
```
