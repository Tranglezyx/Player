# 人物模块

> 修仙者（Cultivator）的属性和表现定义

## 实体结构

```js
class Cultivator {
  // === 基本信息 ===
  name: string;               // 道号
  realmIndex: number;         // 境界序号（0=炼气 1=筑基 2=金丹 ...）
  realm: string;              // 境界名称
  level: number;              // 小等级（1~10，境界突破后重置为 1）

  // === 战斗属性 ===
  attack: number;             // 攻击力
  attackSpeed: number;        // 攻击间隔（秒）
  critRate: number;           // 暴击率
  critDamage: number;         // 暴击伤害倍率

  // === 灵力 ===
  spirit: number;             // 当前灵力值
  maxSpirit: number;          // 灵力上限
  spiritRegen: number;        // 灵力每秒回复量

  // === 修炼属性 ===
  cultivation: number;        // 当前修为值
  maxCultivation: number;     // 突破所需修为值
  cultivationSpeed: number;   // 每秒修为获取（基础 + 心法加成）
  spiritStone: number;        // 灵石数量
  autoCultivate: boolean;     // 自动修炼开关（默认开启）

  // === 装备 ===
  equipment: {
    weapon: Equipment|null;   // 武器 — 攻击力
    helmet: Equipment|null;   // 头盔 — 灵力上限
    armor: Equipment|null;    // 衣服 — 灵力回复速度
    boots: Equipment|null;    // 鞋子 — 攻击速度
    accessory: Equipment|null;// 饰品 — 暴击率/特殊效果
  };

  // === 功法 ===
  innerSkills: InnerSkill[];  // 心法（影响修炼）
  outerSkills: OuterSkill[];  // 术法（影响战斗）

  // === 表现 ===
  x: number;                  // 屏幕坐标（固定位置，底部中央）
  y: number;
  sprite: Image;              // 像素风角色精灵
  state: 'idle'|'attack'|'cultivate'|'breakthrough';
}
```

## 属性来源

```
最终属性 = 基础属性（境界 + 小等级） + 装备加成 + 术法被动加成
```

| 属性 | 基础来源 | 装备加成 | 术法/心法加成 |
|------|---------|---------|-------------|
| 攻击力 | 境界 | 武器 | 被动术法 |
| 攻击速度 | 境界 | 鞋子 | 被动术法 |
| 灵力上限 | 境界 | 头盔 | 被动术法 |
| 灵力回复 | 境界 | 衣服 | 心法 |
| 暴击率 | 境界（固定5%） | 饰品 | 被动术法 |
| 修炼速度 | 固定1/s | — | 心法 |

## 灵力机制

```
灵力 = 释放术法的消耗资源

获取方式：
  - 境界突破：大幅提升灵力上限和回复速度
  - 装备：头盔 +灵力上限，衣服 +回复速度
  - 心法/术法被动：加成

消耗方式：
  - 主动术法每次释放消耗固定灵力值
  - 灵力不足时无法释放术法，仅能普通攻击

回复方式：
  - 每秒自动回复（spiritRegen 点/秒）
  - 怪物死亡时可额外回复少量灵力（可选）
```

## 动画状态

| 状态 | 触发条件 |
|------|---------|
| `idle` | 无战斗时站立待机 |
| `attack` | 每次普攻/术法释放播放动画 |
| `cultivate` | 修炼时打坐动画（可选，Phase 2） |
| `breakthrough` | 境界突破时特效（金光/雷劫） |

> 修炼者不会死亡，所以不需要受击/死亡动画。
