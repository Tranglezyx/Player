# 修炼模块

> 修炼是提升境界的唯一方式，与打怪解耦

## 修炼机制

```
修炼循环：
  1. 每秒自动消耗 N 灵石 → 转化 M 修为值
  2. 修为满 → 小等级自动 +1（修为清零，属性小涨）
  3. 小等级达到 10 且修为满 → "突破"按钮亮起 → 手动突破进入下一境界
  4. 灵石不足时修炼自动暂停
```

### 修炼速度公式

```
基础速度 = 1 修为/秒（全境界固定）
心法加成 = 所有已装备心法的修炼速度加成之和
实际速度 = 基础速度 * (1 + 心法加成)

灵石消耗 = 修炼速度 * 灵石消耗系数（随境界递增）
```

### 每级修为公式

```
修为公式：
  境界基数(realmBase) = 600 × 1.6^(境界序号)
  等级倍率 = 1 + 0.15 × (小等级 - 1)
  所需修为 = ceil(境界基数 × 等级倍率)

同一境界内，每升一级所需修为递增 15%
```

### 修炼状态

| 状态 | 条件 | 表现 |
|------|------|------|
| 修炼中 | 灵石 > 0 且修为未满 | 顶部显示每秒修为增长 |
| 修炼暂停 | 灵石不足 | 图标变灰，提示"灵石不足" |
| 自动降级 | 灵石=0 持续超过 1 分钟 | 自动切换到最高效低级地图刷灵石，灵石恢复后可切回 |
| 自动升级 | 修为满 且 小等级 < 10 | 修为归零，小等级 +1，属性微涨 |
| 可突破 | 修为满 且 小等级 = 10 且 灵石 ≥ 突破消耗 | "突破"按钮高亮 |
| 突破中 | 玩家点击突破 | 播放突破动画 |

> **安全网机制**：当灵石连续 60 秒为 0 时，系统自动将地图切换为"推荐地图"（等阶匹配当前等级），确保战斗灵石收入最大化，防止灵石枯竭死循环。

## 离线修炼

```
离线收益 = 在线每分钟收益 × 离线总分钟数

规则：
  - 无离线系数：离线多久就拿多少，不缩水
  - 灵石和修为分开计算
  - 离线期间同样消耗灵石用于修炼，灵石归零后修炼自动停止（剩余时间不再产生修为）
  - 离线心法熟练度按在线速率 50% 累积（有上限：最多累积 8 小时）
  - 离线收益结算时显示明细弹窗：
    "你离开了 2h 30m，获得：
      灵石 +27,000
      修为 +1,800
      （修炼消耗灵石 -4,500）"
```

离线收益在进入游戏时一次性结算弹窗展示。

> 注意：境界突破需要手动操作，离线期间不会自动突破。
