# 修炼模块

> 修炼是提升境界的唯一方式，与打怪解耦

## 修炼机制

```
修炼循环：
  1. 每秒自动消耗 N 灵石 → 转化 M 修为值
  2. 修为值积累到满 → 可点击"突破"
  3. 灵石不足时修炼自动暂停
  4. 突破消耗额外灵石 → 进入新境界
```

### 修炼速度公式

```
基础速度 = 1 修为/秒（全境界固定）
心法加成 = 所有已装备心法的修炼速度加成之和
实际速度 = 基础速度 * (1 + 心法加成)

灵石消耗 = 修炼速度 * 灵石消耗系数（随境界递增）
```

### 各境界修炼数值

| 境界 | 灵石消耗/秒 | 突破所需修为 | 突破消耗灵石 |
|------|-----------|------------|------------|
| 炼气期 | 1 | 600 | 50 |
| 筑基期 | 3 | 3,000 | 300 |
| 金丹期 | 10 | 15,000 | 2,000 |
| 元婴期 | 30 | 60,000 | 15,000 |
| 化神期 | 100 | 300,000 | 100,000 |

（后续境界指数递增，具体数值待 Phase 2 调优）

## 修炼状态

| 状态 | 条件 | 表现 |
|------|------|------|
| 修炼中 | 灵石 > 0 且修为未满 | 顶部显示每秒修为增长 |
| 修炼暂停 | 灵石不足 | 图标变灰，提示"灵石不足" |
| 可突破 | 修为已满 且 灵石 ≥ 突破消耗 | 修炼面板高亮"突破"按钮 |
| 突破中 | 玩家点击突破 | 播放突破动画 |

## 离线修炼

```
离线修炼收益 = 修炼速度 * 离线时长 * 离线系数 * (1 + 心法离线加成)

离线系数：
  ≤ 2小时 ：100%
  2-8小时 ：80%
  8-24小时：50%
  > 24小时：封顶 24h * 50%

注意：离线修炼同样消耗灵石，灵石不足则按比例缩减修为收益
```

离线收益在进入游戏时一次性结算弹窗展示。
