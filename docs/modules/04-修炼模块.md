# 修炼模块

> 修炼是提升境界的唯一方式，与打怪解耦

## 修炼机制

```
修炼循环：
  1. 每秒自动消耗 N 灵石 → 转化 M 修为值
  2. 修为满 → 小等级自动 +1（修为清零，属性小涨）
  3. 小等级达到 10 且修为满 → "突破"按钮亮起 → 手动突破进入下一境界
  4. 灵石不足时修炼自动暂停
```

### 修炼速度公式

```
基础速度 = 1 修为/秒（全境界固定）
心法加成 = 所有已装备心法的修炼速度加成之和
实际速度 = 基础速度 * (1 + 心法加成)

灵石消耗 = 修炼速度 * 灵石消耗系数（随境界递增）
```

### 每级修炼数值

| 境界 | 灵石消耗/秒 | 每级所需修为 | 突破消耗灵石 |
|------|-----------|------------|------------|
| 炼气期 | 1 | 600 | 50 |
| 筑基期 | 3 | 1,500 | 300 |
| 金丹期 | 10 | 3,000 | 2,000 |
| 元婴期 | 30 | 6,000 | 15,000 |
| 化神期 | 100 | 12,000 | 100,000 |

> 每级修为 = 基础值 × [1 + 0.2 × (当前小等级 - 1)]，即同一境界内越往后越难升

### 修炼状态

| 状态 | 条件 | 表现 |
|------|------|------|
| 修炼中 | 灵石 > 0 且修为未满 | 顶部显示每秒修为增长 |
| 修炼暂停 | 灵石不足 | 图标变灰，提示"灵石不足" |
| 自动升级 | 修为满 且 小等级 < 10 | 修为归零，小等级 +1，属性微涨 |
| 可突破 | 修为满 且 小等级 = 10 且 灵石 ≥ 突破消耗 | "突破"按钮高亮 |
| 突破中 | 玩家点击突破 | 播放突破动画 |

## 收益展示

界面顶部实时显示每分钟收益：

```
灵石: 12345  (+180/分钟)    修为: 67%  (+12/分钟)
```

## 离线修炼

```
离线收益 = 在线每分钟收益 × 离线总分钟数

规则：
  - 无离线系数：离线多久就拿多少，不缩水
  - 灵石和修为分开计算
  - 离线收益结算时显示明细弹窗：
    "你离开了 2h 30m，获得：
     灵石 +27,000
     修为 +1,800
     （修炼消耗灵石 -4,500）"
```

离线收益在进入游戏时一次性结算弹窗展示。

> 注意：离线期间同样消耗灵石用于修炼，若灵石不足则修为收益按比例缩减
