# 装备模块

> 装备的掉落、品质、穿戴与属性加成

## 装备部位

| 部位 | 主要属性加成 |
|------|------------|
| 武器 | 攻击力 |
| 头盔 | 灵力上限 |
| 衣服 | 灵力回复速度 |
| 鞋子 | 攻击速度 |
| 饰品 | 暴击率、暴击伤害、特殊效果 |

## 装备品质

| 品质 | 颜色 | 属性倍率 | 掉落概率（基础） |
|------|------|---------|----------------|
| 凡品 | 白 | 1.0x | 70% |
| 良品 | 绿 | 1.3x | 20% |
| 上品 | 蓝 | 1.7x | 7% |
| 极品 | 紫 | 2.2x | 2.5% |
| 仙品 | 橙 | 3.0x | 0.4% |
| 神器 | 红 | 5.0x + 随机词缀 | 0.1% |

## 装备数据结构

```js
class Equipment {
  id: string;
  name: string;           // 名称（如"玄铁剑"）
  slot: string;           // 部位 'weapon'|'helmet'|'armor'|'boots'|'accessory'
  quality: string;        // 品质
  qualityIndex: number;   // 0~5
  stats: {
    attack?: number;
    maxSpirit?: number;      // 灵力上限
    spiritRegen?: number;    // 灵力回复速度
    attackSpeed?: number;
    critRate?: number;
    critDamage?: number;
  };
  affix: string|null;     // 神器独有词缀
}
```

## 各部位属性分配

| 部位 | 主属性 | 满级基础值（凡品） | 成长方式 |
|------|-------|-----------------|---------|
| 武器 | 攻击力 | +5 | 品质 * 境界系数 |
| 头盔 | 灵力上限 | +20 | 品质 * 境界系数 |
| 衣服 | 灵力回复速度 | +0.5/s | 品质 * 境界系数 |
| 鞋子 | 攻击速度（减少间隔） | -0.1s | 品质 * 境界系数 |
| 饰品 | 暴击率 +2% | 或暴击伤害 +20% | 品质 * 境界系数 |

## 掉落机制

- 怪物死亡时按掉落表概率判定
- 先判定是否掉落装备 → 再判定品质 → 再判定部位
- 掉落物短暂停留（3 秒）后自动拾取
- 品质越高掉落概率越低

## 背包

- 背包容量：初始 30 格（可扩展）
- 一键出售：按品质筛选出售换灵石
- 自动穿戴：获得更高品质同部位装备时自动替换，旧装备进入背包
