# 商店模块

> 消耗灵石购买法术和装备，定时刷新，可锁定商品

## 刷新机制

| 规则 | 说明 |
|------|------|
| 刷新间隔 | 每 5 小时自动刷新一次（在线计时，非现实时间） |
| 商品数量 | = 人物当前等级（如 15 级 = 15 件商品） |
| 手动刷新 | 可消耗灵石提前刷新（费用递增） |
| 锁定 | 锁定后该商品不受自动/手动刷新影响 |

### 刷新倒计时

```
商店顶部显示倒计时： "下次刷新: 3h 24m"
自动刷新时间到达 → 商店清空 → 生成新商品 → 倒计时重置为 5h
被锁定的商品保留，不参与清空
```

### 锁定规则

| 规则 | 说明 |
|------|------|
| 锁定操作 | 点击商品旁的锁图标，切换锁定/解锁 |
| 锁定数量 | 不限，但每件锁定的商品占用一个刷新槽位 |
| 刷新行为 | 锁定商品不消失、不被替换 |
| 购买后 | 购买锁定商品后自动解锁并移除 |

```
示例：
  人物 15 级 → 商店刷新 15 件商品
  锁定 3 件 → 下次自动刷新只刷新剩余 12 个槽位
  总商品仍保持 15 件（3 锁定 + 12 新）
```

## 商品池

### 法术类商品

| 商品 | 类型 | 价格（灵石） | 出现权重 |
|------|------|------------|---------|
| 飞剑术·残卷 | 术法-主动 | 30 | 15% |
| 雷霆咒·残卷 | 术法-主动 | 50 | 10% |
| 烈火掌·残卷 | 术法-主动 | 40 | 10% |
| 吐纳术·残卷 | 心法 | 40 | 15% |
| 静心诀·残卷 | 心法 | 60 | 10% |
| 破障心经·残卷 | 心法 | 80 | 8% |
| 完整飞剑术 | 术法-主动 | 300 | 3% |
| 完整吐纳术 | 心法 | 400 | 2% |

> 残卷：集齐 N 张（如 3~5 张）合成完整功法。完整功法直接出售概率低、价格高。

### 装备类商品

装备按当前境界生成，品质随机（凡品~神器）：

| 部位 | 基础价格 | 品质倍率 |
|------|---------|---------|
| 武器 | 80 | 白1x / 绿2x / 蓝5x / 紫15x / 橙40x / 红100x |
| 头盔 | 60 | 同上 |
| 衣服 | 60 | 同上 |
| 鞋子 | 50 | 同上 |
| 饰品 | 100 | 同上 |

```
实际价格 = 基础价格 × 品质倍率 × 境界系数（境界越高越贵）
```

## 手动刷新

| 操作 | 消耗 | 说明 |
|------|------|------|
| 手动刷新 | 50 × 境界系数 灵石 | 立即刷新所有未锁定槽位，重置倒计时 |
| 价格递增 | 每次手动刷新后下次 +20% | 刷新 3 次后恢复原价（隔日重置） |

## 购买流程

```
点击商品 → 弹出确认框
  ├─ 灵石不足 → 提示"灵石不足"
  ├─ 已拥有该功法 → 提示"已习得"（不可重复购买功法）
  └─ 灵石足够 → 扣除灵石 → 物品进入背包/功法列表 → 商品移除
```
