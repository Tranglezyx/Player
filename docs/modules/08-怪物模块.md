# 怪物模块

> 怪物按等阶分布在不同地图，玩家自由选择地图战斗

## 地图与等阶

### 设计规则

```
- 怪物以 5 级为一个等阶（如等阶 1 = Lv1~5，等阶 2 = Lv6~10）
- 每个地图包含 1~2 个等阶的怪物
- 地图随对应等阶解锁
- 玩家可自由切换已解锁的地图
- 修炼者不会死亡，怪物仅有 HP 和防御
```

## 怪物属性

```js
class Monster {
  name: string;           // 名称
  tier: number;           // 等阶（1~20）
  hp: number;
  maxHp: number;
  defense: number;        // 修炼者不会死亡，无需怪物攻击力

  // 掉落
  stoneBase: number;      // 基础灵石掉落
  stoneRange: number;     // 灵石浮动范围

  // 外观
  sprite: Image;
  state: 'idle'|'hurt'|'dead';
}
```

## 掉落机制

| 掉落物 | 概率 | 说明 |
|--------|------|------|
| 灵石 | 100% | 每次击杀必掉，数量在等阶范围内随机 |
| 法术碎片 | 5% | 低概率掉落，具体碎片类型由等阶决定 |
| 装备 | 0% | 装备不出自怪物，仅从商店购买 |

### 法术碎片掉落表

不同等阶掉落不同的法术碎片：

| 等阶范围 | 可掉落碎片 |
|---------|-----------|
| 等阶 1~3 | 飞剑术碎片、吐纳术碎片 |
| 等阶 4~6 | 雷霆咒碎片、静心诀碎片、炼体诀碎片 |
| 等阶 7~10 | 烈火掌碎片、天元心法碎片、剑心通明碎片 |
| 等阶 11~15 | 破障心经碎片、玄元功碎片、杀戮领域碎片 |
| 等阶 16~20 | 聚灵阵碎片、长生经碎片、高阶功法碎片 |

### 碎片合成

```
3 张同种碎片 → 1 本完整功法（直接习得）

背包中显示碎片数量：
  飞剑术碎片 ×2（还需 1 张合成）
  吐纳术碎片 ×3（可合成！）
```
