# 战斗模块

> 全自动战斗循环、伤害计算、灵力消耗、怪物管理

## 战斗流程

```
1. 怪物从对象池生成，显示在屏幕中上部固定位置
2. 修炼者按攻击间隔自动普通攻击
3. 灵力充足 + 术法冷却完毕 → 消耗灵力释放主动术法
4. 灵力不足时仅普通攻击，等待灵力自动回复
5. 怪物 HP 归零 → 死亡 → 发放灵石 → 重生计时 → 新怪物
```

## 伤害计算

```
基础伤害 = max(1, 修炼者攻击力 - 怪物防御力)

暴击判定：
  随机数 < 暴击率 → 暴击伤害 = 基础伤害 * 暴击倍率
  否则 → 普通伤害 = 基础伤害

术法加成：
  术法伤害 = 基础伤害 * 术法技能倍率
```

## 灵力消耗规则

| 规则 | 说明 |
|------|------|
| 术法消耗 | 每个主动术法有固定灵力消耗（如飞剑术 10 灵力、雷霆咒 15 灵力） |
| 不足时 | 灵力不足以释放术法时，跳过该术法，仅普攻 |
| 回复速度 | 每秒自动回复（基础 1/s + 装备 + 心法加成） |
| 战斗回复 | 怪物死亡回复少量灵力（如 5~10 点） |

## 修炼者攻击行为

| 行为 | 消耗 | 说明 |
|------|------|------|
| 普通攻击 | 无消耗 | 按攻击间隔自动普攻 |
| 术法释放 | 消耗灵力 | 冷却完毕 + 灵力足够时自动释放，伤害 = 普攻 * 术法倍率 |
| 攻击目标 | — | 优先攻击当前怪物，死亡后自动切换 |

**关键设定**：
- 修炼者不会死亡，HP/防御属性已移除
- 不需要手动操作，全自动
- 灵力不足时降级为纯普攻，适合"灵力真空期"的挂机体验

## 怪物（Monster）

```js
class Monster {
  name: string;           // 名称（妖兽/小妖/魔修...）
  level: number;
  hp: number;
  maxHp: number;
  attack: number;
  defense: number;

  // 掉落
  stoneReward: number;   // 击杀灵石奖励
  dropTable: DropItem[]; // 掉落表

  // 表现
  x: number;              // 固定位置（屏幕中上部）
  y: number;
  sprite: Image;
  state: 'idle'|'attack'|'hurt'|'dead';

  respawnCooldown: number; // 死亡后重生等待时间
}
```

### 怪物属性匹配

```
怪物属性 ≈ 同境界修炼者属性的 40%~60%
灵石掉落 ≈ 每秒修炼消耗 * 2~5（确保修炼可持续）
击杀时间 ≈ 5~15 秒/只（取决于术法强度）
```

## 伤害数字（DamageNumber）

```js
class DamageNumber {
  value: number;       // 伤害数值
  x: number;
  y: number;
  alpha: number;       // 透明度（渐隐消失）
  vy: number;          // 向上浮动速度
  color: string;       // 颜色区分
  isCrit: boolean;     // 是否暴击
}
```

| 类型 | 颜色 | 特效 |
|------|------|------|
| 普通伤害 | 白色 | 普通浮动 |
| 暴击 | 黄色 | 字体放大 + 浮动 |
| 术法伤害 | 蓝色 | 字体放大 + 浮动 |

## 掉落物（DropItem）

```js
class DropItem {
  item: Item;          // 掉落物品数据
  x: number;
  y: number;
  collected: boolean;  // 是否已拾取
  flytoTarget: boolean; // 是否正飞向玩家
}
```

掉落物 3 秒停留后自动飞向修炼者，或点击提前拾取。
