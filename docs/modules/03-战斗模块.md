# 战斗模块

> 全自动战斗循环、伤害计算、灵力消耗、地图切换

## 战斗流程

```
1. 玩家选择修炼地图（或延续上次地图）
2. 从地图对应的等阶怪物池随机选取怪物，从对象池生成
3. 修炼者按攻击间隔自动普通攻击
4. 灵力充足时自动释放主动术法（灵力≥术法消耗即释放）
5. 灵力不足时仅普通攻击，等待灵力自动回复
6. 怪物 HP 归零 → 死亡 → 发放灵石 + 概率掉落碎片 → 重生计时 → 新怪物
```

## 地图切换

```
主场景顶部显示当前地图名 → 点击弹出地图选择面板

已解锁的地图可自由切换：
  - 低等阶地图：怪物弱、灵石少，但击杀快（刷碎片用）
  - 高等阶地图：怪物强、灵石多，但击杀慢（刷灵石用）
  - 推荐地图：与当前玩家等级匹配的等阶（最佳效率）

切换地图后，当前怪物直接替换为新地图怪物。
```

## 伤害计算

```
基础伤害 = 攻击力² / (攻击力 + 怪物防御)
  → 当攻击 = 防御时，伤害 ≈ 攻击/2
  → 当攻击 >> 防御时，伤害 ≈ 攻击
  → 当攻击 << 防御时，伤害 ≈ 攻击²/防御（仍有伤害，不会归零）

暴击判定：
  随机数 < 暴击率 → 暴击伤害 = 基础伤害 × 暴击倍率
  否则 → 普通伤害 = 基础伤害

术法加成：
  术法伤害 = 基础伤害 × 术法技能倍率
```

## 灵力消耗规则

| 规则 | 说明 |
|------|------|
| 术法消耗 | 每个主动术法有固定灵力消耗 |
| 不足时 | 灵力不足以释放术法时，跳过该术法，仅普攻 |
| 回复速度 | 每秒自动回复（基础 + 装备 + 心法加成） |
| 战斗回复 | 怪物死亡回复少量灵力 |

## 修炼者攻击行为

| 行为 | 消耗 | 说明 |
|------|------|------|
| 普通攻击 | 无消耗 | 按攻击间隔自动普攻 |
| 术法释放 | 消耗灵力 | 灵力 ≥ 消耗时自动释放 |
| 攻击目标 | — | 优先攻击当前怪物，死亡后自动切换 |

**关键设定**：
- 修炼者不会死亡，怪物无攻击力
- 不需要手动操作，全自动
- 灵力不足时降级为纯普攻

## 怪物（Monster）

属性和等阶详见 [[08-怪物模块]]，此处仅保留数据结构：

```js
class Monster {
  name: string;           // 名称
  tier: number;           // 等阶（1~20）
  hp: number;
  maxHp: number;
  defense: number;

  // 掉落
  stoneBase: number;      // 基础灵石
  stoneRange: number;     // 灵石浮动 ±
  fragmentDropRate: number; // 碎片掉落概率（基础 5%）

  // 表现
  x: number;
  y: number;
  sprite: Image;
  state: 'idle'|'hurt'|'dead';
}
```

## 掉落结算

```
怪物死亡 → 灵石直加（等阶范围内随机浮点） → 弹出 "+灵石 x50"
         → 概率判定碎片（5%基础） → "获得 [飞剑术碎片]"
         → 弹出提示条
```

> 装备不出自怪物，仅从商店购买。碎片可用于合成完整功法。

## 伤害数字（DamageNumber）

```js
class DamageNumber {
  value: number;
  x: number;
  y: number;
  alpha: number;       // 渐隐
  vy: number;          // 上浮速度
  color: string;       // 白=普攻 黄=暴击 蓝=术法
  isCrit: boolean;
}
```
