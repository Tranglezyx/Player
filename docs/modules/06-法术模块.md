# 法术模块

> 功法分为心法（修炼侧）和术法（战斗侧），均有熟练度系统

## 两大分类

| 类别 | 作用域 | 熟练度来源 |
|------|-------|-----------|
| **心法** (InnerSkill) | 修炼效率、修为上限、突破消耗 | 消耗灵石修炼自动积累 |
| **术法** (OuterSkill) | 战斗伤害、被动属性、光环效果 | 释放技能 / 击杀怪物 |

## 熟练度系统

```
入门(0次) → 小成(100次) → 大成(500次) → 圆满(2000次) → 化境(5000次)

倍率：入门 1.0x → 小成 1.3x → 大成 1.7x → 圆满 2.2x → 化境 3.0x
```

### 心法数据结构

```js
class InnerSkill {
  id: string;               // 'breath_art','clear_mind',...
  name: string;             // 心法名称
  proficiency: number;      // 当前熟练度（消耗灵石数 / 因子）
  proficiencyLevel: number; // 0=入门 1=小成 2=大成 3=圆满 4=化境
  baseEffect: number;       // 基础倍率
  effectType: string;       // 'cultivateSpeed'|'cultivateCap'|'breakthroughCost'|'offlineBonus'

  getEffect() {
    const M = [1.0, 1.3, 1.7, 2.2, 3.0];
    return this.baseEffect * M[this.proficiencyLevel];
  }
}
```

### 术法数据结构

```js
class OuterSkill {
  id: string;
  name: string;
  type: 'active'|'passive'|'aura';
  proficiency: number;
  proficiencyLevel: number;  // 0~4
  baseEffect: number;
  spiritCost: number;        // 仅主动技能，灵力消耗

  getEffect() {
    const M = [1.0, 1.3, 1.7, 2.2, 3.0];
    return this.baseEffect * M[this.proficiencyLevel];
  }
}
```

## 功法获取

| 方式 | 说明 |
|------|------|
| 境界突破 | 每个境界解锁 1-2 个新功法 |
| 残卷合成 | 打怪低概率掉落残卷，集齐 N 张合成 |
| 商店购买 | 消耗灵石直接购买 |
