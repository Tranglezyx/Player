# 美术设计文档

> 像素风修仙挂机游戏的视觉与音频设计规范

## 1. 整体风格

| 项 | 说明 |
|----|------|
| 画风 | 像素风（Pixel Art），参考 32-bit 复古 RPG |
| 色调 | 中式古风暖色调为主，境界越高颜色越华丽 |
| 氛围 | 静谧中带仙气，不同区域有差异化环境色 |

## 7. UI 设计

### 字体

| 用途 | 字号 | 字体风格 |
|------|------|---------|
| 面板标题 | 20px | 粗体，居中 |
| 正文/属性 | 15-16px | 常规 / 粗体 |
| 伤害数字 | 18-22px | 粗体，像素风 |
| 小字/提示 | 13-14px | 辅助说明 |

> 字体：使用系统 sans-serif，在微信小游戏环境中绘制 Canvas 文字

### 面板样式

- **实现方式**：Canvas 2D 绘制（`js/ui/uiPainter.js` 提供统一绘制函数）
- **仿古书卷风格**：四角古铜金色装饰（`#C9A96E`）+ 深色半透明背景（`#1A1A2E`）
- **标题栏**：面板顶部 40px 区域，中心装饰线，标题金色居中
- **弹窗遮罩**：黑色 60% 透明度，面板居中，高度为中间区域 75%
- **按钮**：圆角古铜边框，正常态带顶部高光，按下凹陷效果
- **进度条**：暗色底 + 渐变色填充 + 高光条 + 古铜边框
- **像素图标**：Canvas 绘制（灵石菱形、修为莲花、灵力水滴、攻击小剑、底部导航各种图标）
- **品质标签**：圆角色边框徽章，按装备品质着色
- **列表**：交替行背景，激活行金色边框

### 底部导航按钮

| 按钮 | 图标说明 | 像素尺寸 |
|------|---------|---------|
| 修炼 | 蒲团/打坐小人 | 48×48 |
| 功法 | 展开的竹简/书卷 | 48×48 |
| 背包 | 乾坤袋 | 48×48 |
| 商店 | 铜钱/聚宝盆 | 48×48 |

> 地图切换已整合到顶部栏，点击地图名弹出地图面板。底部仅保留 4 个按钮。

## 8. 特效设计

### 战斗特效

| 特效 | 说明 | 帧数 | 尺寸 |
|------|------|------|------|
| 普攻斩击 | 白色弧形刀光 | 2 帧 | 32×32 |
| 飞剑术 | 一把旋转的飞剑飞向怪物 | 持续动画 | 48×48 |
| 雷霆咒 | 从天而降的闪电 | 3 帧 | 48×64 |
| 暴击特效 | 黄色爆炸星芒 | 3 帧 | 64×64 |
| 怪物死亡 | 像素碎片消散 | 4 帧 | 64×64 |

### 修炼特效

| 特效 | 说明 |
|------|------|
| 修炼中 | 角色周围灵气粒子缓慢上升 |
| 突破 | 金光柱从角色位置冲天而起 + 屏幕震动 |
| 渡劫（后期） | 天雷从天劈下，角色硬扛 |

### 掉落提示

物品直接进背包，顶部弹出文字提示，无需掉落物视觉特效。

- 灵石：右上角灵石数跳动 + 绿色 "+xx"
- 装备/残卷：屏幕顶部弹出半透明提示条 "获得 [玄铁剑]"
