## 2. 场景架构

### 场景列表

| 场景 | 类型 | 用途 |
|------|------|------|
| 战斗主场景 | Canvas 渲染层 | 固定战斗画面，角色+怪物+伤害数字+掉落物 |
| 修炼面板 | 弹出层（DOM/HUD） | 境界信息、修炼进度、突破按钮 |
| 功法面板 | 弹出层 | 心法/术法两个标签页 |
| 背包面板 | 弹出层 | 装备列表、穿戴、出售 |
| 商店面板 | 弹出层 | 灵石购买法术/装备，刷新倒计时 |
| 地图面板 | 弹出层 | 选择修炼地图，查看解锁状态 |
| 设置面板 | 弹出层 | 声音、重置等 |

> 说明：微信小游戏没有 DOM，这里说的"面板"是通过 Canvas 绘制的半透明遮罩 + 按钮区域。

## 3. 可复用现有模块

| 现有文件 | 说明 | 复用方式 |
|---------|------|----------|
| `js/base/sprite.js` | 精灵基类（图片加载、绘制、碰撞检测） | 直接复用 |
| `js/base/animation.js` | 帧动画（攻击/爆发/突破特效） | 直接复用 |
| `js/base/pool.js` | 对象池（怪物、伤害数字、掉落物） | 直接复用 |
| `js/render.js` | Canvas 创建 + 屏幕尺寸 | 直接复用 |
| `js/libs/tinyemitter.js` | 事件总线 | 直接复用 |
| `js/runtime/background.js` | 背景渲染 | 改造为静态/视差背景 |
| `js/runtime/music.js` | 音效管理 | 直接复用 |
| `js/databus.js` | 全局状态管理 | 扩展改造 |

## 4. 技术栈

| 项 | 选择 |
|----|------|
| 语言 | JavaScript (ES6+) |
| 渲染 | Canvas 2D |
| 目标帧率 | 60 FPS |
| 存储 | `wx.setStorageSync` / `wx.getStorageSync` |
| 架构模式 | 场景-实体-系统（ECS 简化版） |
